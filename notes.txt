    -> Python Syntax / Rules / Best Practices 

        -> Any Python File We Write, should have extension as .py 

            -> demo.py or app.py 

        -> Python Ignores Any Line That Starts With # 

            -> # Means Comments 

        -> In Python We Have Functions, which does some task 

            -> Functions have name function_name() 

            -> NOTE: We Have print() - Prints Values On Standard Output 

        -> When Working With Numeric Values (1,2,1.5,-10 etc)
        we can directly use print()

        -> When Working With Text Values, we call them as Strings 

            -> Rule / Syntax: Strings should be enclosed in ' ' or " " 


    
    -> Identifiers 

        -> An Identifier is a "Name" used to Uniquely Identify a piece of data in code

            -> Variables 

            -> Functions 

            -> Classes 

            -> Objects 

            -> Methods  

            -> etc 

        -> Just Like Gmail Giving Invalid email for given input 

            -> #%&@&@^@ (Enter a valid email)

        -> Identifier Rules 

            -> Can Contain 

                -> Alphabets (a-z A-Z)
                -> Digits (0-9)
                -> Special Symbols (Only _ (underscore) is allowed)

            -> Must Start With 

                -> An Alphabet or _ (underscore)

        -> NOTE: Always Use Proper Way Of Naming Identifiers 

        -> NOTE: Always Use UPPER CASE for Static Data (Fixed / Doesn't Change)
